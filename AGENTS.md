# StyleConnect - WhatsApp E-Commerce Store Demo

This repository contains a standalone demo e-commerce store with WhatsApp integration built using TanStack Start, React 19, Vite, and Tailwind CSS.

## Key Features
- **Direct 1-Click WhatsApp Ordering**: Instant item order buttons that generate pre-formatted WhatsApp chat inquiries.
- **WhatsApp Bag & Checkout Drawer**: Multi-item cart with automatic price calculation and structured WhatsApp order receipts.
- **Client Demo Controls**: Interactive demo banner, floating WhatsApp quick-chat widget, and prospective client showcase sections.
